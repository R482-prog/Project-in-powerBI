# Data Professional Survey Breakdown Dashboard

![Dashboard Screenshot](./Screenshot%202025-04-23%20120534.png)

## 📊 Overview

This Power BI dashboard provides insights from a survey of data professionals across various roles and countries. It helps to understand trends in job titles, salaries, countries of respondents, 
favorite programming languages, and workplace satisfaction.

---

## 🔍 Key Highlights

- **Average Salary by Job Title**  
  Compares average salaries across roles like Data Scientist, Data Engineer, Data Architect, and more.

- **Country of Survey Takers**  
  A tree map displaying the geographical distribution of respondents, with the United States, India, and other countries represented.

- **Survey Demographics**  
  - **Average Age of Respondents:** 29.87  
  - **Total Respondents:** 630

- **Workplace Satisfaction**  
  - **Happiness with Work-Life Balance:** 5.74 / 10  
  - **Happiness with Salary:** 4.27 / 10

- **Favorite Programming Languages**  
  Python dominates as the top language, followed by R and others, categorized by job title.

## 🧠 Insights

- **Python** remains the dominant programming language among data professionals, especially data analysts.
- **Data Scientists** report the highest average salaries.
- **Work-life balance** is rated moderately, while **salary satisfaction** is relatively low.
- The majority of respondents are from the **United States**.

---

## 🛠 Tools Used

- Microsoft Power BI
- Data collected from a professional survey of 630 participants
